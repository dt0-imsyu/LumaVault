# LumaVault

Portfolio-ready Flutter fintech app with authentication, live exchange-rate integration, budget analytics, transaction risk scoring, and a multi-tab product shell.

## Highlights

- Flutter Material 3 Android app
- Auth-first flow with a polished financial dashboard
- Repository layer and API client
- Live EUR exchange rates from Frankfurter API with offline fallback
- AI-style budget insights, risk-scored transactions, and spending buckets
- Widget smoke test and static analysis ready

## Tech

- Flutter 3.44
- Dart 3.12
- `http`
- Material 3

## Run

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d <device-id>
```
